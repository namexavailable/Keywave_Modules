# KW307 SDK, GUI and examples (v2.17.6)

Software for the Keywave **KW307** 24 GHz mmWave presence radar module.

| Path | What it is |
|---|---|
| `KW307_SDK/` | Portable C SDK (v2.17.6, FW 2.11.0), platform ports and docs. Start with `KW307_SDK/README.md` |
| `GUI/KW307_GUI_B.6_20261110.html` | Browser GUI over UART (Web Serial, Chrome or Edge). Open the file, pick the port, press Connect |
| `ESP32_KW307_base/` | ESP32 Arduino sketch that serves a WiFi dashboard for the KW307. See its `README.md` |
| `KW307_SDK_User_Guide.html` | SDK user guide (same as `KW307_SDK/doc/`) |
