Place the SDK folder in your library directory. For example, if you are using the Arduino IDE, put the SDK in:
C:\Users\your_name\Documents\Arduino\libraries

Some IDEs may not function properly if the SDK is placed in the wrong folder. Refer to the IDE documentation or consult an AI assistant to determine the correct location.

Also, do not place multiple copies of the same SDK in the libraries folder. The IDE may fail to function correctly if it detects duplicate .c or .h files with the same names.
